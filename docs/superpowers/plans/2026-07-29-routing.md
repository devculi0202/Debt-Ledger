# Client-side Routing Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace `activeTab` / session-gate view switching with React Router URLs (`/`, `/login`, `/master-debts`, `/transactions`) and bidirectional auth redirects.

**Architecture:** Add `react-router-dom` with `BrowserRouter` in `main.jsx`. Extract `LoginPage`, add a thin `ProtectedRoute` that redirects unsigned users to `/login`, and nest authenticated views under it. Keep session, data fetching, filters, and modals in `App.jsx`; routing only selects which view renders. Sidebar uses `NavLink` against the pathname.

**Tech Stack:** React 19, Vite 8, `react-router-dom`, existing Supabase auth.

**Spec:** `docs/superpowers/specs/2026-07-29-routing-design.md`

## Global Constraints

- Routes must match the spec table exactly: `/`, `/login`, `/master-debts`, `/transactions`, catch-all `*`.
- Signed out on protected paths → `/login`; signed in on `/` or `/login` → `/master-debts`.
- After OAuth/session established → `/master-debts`; after sign out → `/login`.
- Do not redesign login UI; do not add query-string deep links; do not refactor MasterDebtList / TransactionLedger / modals beyond wiring navigation.
- While initial Supabase session is unresolved, do not flash wrong redirects (`session === undefined` loading hold).
- No automated test suite in this repo; verify with the manual checklist in each task.

### Task 3: Add `ProtectedRoute` and wire all routes in `App`

**Files:**
- Create: `src/components/ProtectedRoute.jsx`

**Interfaces:**
- Consumes: `session` prop — `undefined` (loading), `null` (signed out), or session object (signed in)

- [ ] **Step 1: Create `src/components/ProtectedRoute.jsx`**

```jsx
import { Navigate, Outlet } from 'react-router-dom'

export default function ProtectedRoute({ session }) {
  if (session === undefined) {
    return (
      <div className="bg-neu-bg dark:bg-darkNeu-bg min-h-screen flex items-center justify-center text-neu-textMuted dark:text-darkNeu-textMuted">
        Loading…
      </div>
    )
  }

  if (!session) {
    return <Navigate to="/login" replace />
  }

  return <Outlet />
}
```
